# UX 审计实施状态

日期：2026-08-13

本轮依据 `docs/UX_TEST_AND_IMPROVEMENT_AUDIT_20260813.md`，只实施已有明确代码证据、不会引入新业务模型的改进。

## 已实施

### 已完成待办与今日工作台

- 领域层拒绝把已完成待办加入今日，返回 `409 / TODO_ALREADY_COMPLETED`。
- 被拒绝时不修改今日计划、日期或活动日志。
- AI/MCP 在生成预览前执行同一检查；已完成待办只返回解释，不生成操作预览。
- 合同测试位于 `tests/today-completed-guard.test.mjs`。

### 早晨对焦

- 今日页与右侧 AI 提供同一个早晨对焦工作流入口。
- 复用 `/api/morning/chat` 和当天后端 session，不建立第二套聊天系统。
- 候选事项只供讨论，加入今日仍需用户明确点击。
- 对焦正文不写浏览器持久化存储。

### AI 工作区

- 支持展开、窄条、完全收起三态；只保存面板模式这一 UI 偏好。
- 主界面把模型状态表述为“已配置，未联网验证”。
- 每次结果继续标注模型规划或本地安全回退。
- 工具结果先显示摘要，原始 JSON 收入“查看技术详情”。

### 操作回执

项目同步、飞书收件箱同步、备份、AI 工具执行和今日工作台变更增加可关闭的页内回执，不再只依赖短暂 Toast。回执只存在当前页面内存。

## 暂未实施

以下事项需要独立产品决策，本轮不实施：

- 四象限字段与历史迁移；
- 固定日程的开始/结束时间模型；
- AI 对话收藏及其唯一真源；
- 顶栏重排、全局快速记录轻量化和更大范围视觉重构。

项目分析、阶段总结、复盘和上下文恢复正文继续只保存到绑定的飞书项目文档。

本轮 CI 验证 Node 24 语法、领域/MCP 合同和前端静态合同。没有使用真实外部服务凭证，也不声称完成 live OpenAI、live 飞书、真实 iPhone、真实浏览器设备矩阵或生产部署验证。

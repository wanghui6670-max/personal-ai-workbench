## 3. 已完成的主要工作

### Harness 控制面

- Harness 核心控制面、能力注册、工具代理、策略门、执行和项目会话形成闭环。
- `live authority` 已接入，可信 Project Session 可以关联真实工具运行。

- 运行结束或失败后，可信运行作用域会清理。

### 存储与恢复

- `Execution Store` 和 `Session Store` 使用原子写入与串行写入。
- 支持损坏 JSON 文件恢复，并保留损坏原文件供排查。
- 服务重启时，运行中的执行记录会被正确中断恢复。
- `list({ limit: 0 })` 的边界行为已修复。
- 同一项目的并发 `openProject` 不会重复创建持久化 Session。

### 安全边界

- Git remote 会清理凭证、query 和 fragment，覆盖 HTTP、SSH 和 scp-like 形式。
- Feishu `lark-cli` 子进程只接收审查后的环境变量，避免泄露完整进程环境。
- OpenAI Provider 遵守显式 `AI_PROVIDER_WORKFLOWS` 白名单。
- Crew 派单的 agent id 做了安全校验和 shell quoting。
- Project Knowledge 和 Crew Center 以只读能力接入。
